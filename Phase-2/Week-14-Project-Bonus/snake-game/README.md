# Snake Game

A classic Snake game built with HTML, CSS, and Vanilla JavaScript.

## Project Description

The player controls a continuously moving snake using the keyboard arrow keys.
The snake moves around the game board and grows when it eats food.

The game ends when the snake:

- Collides with the game board boundary
- Collides with its own body

The game displays the current score and high score. After game over, the
player can restart the game and play again.

## Features

- Keyboard arrow-key controls
- Continuous snake movement
- Random food generation
- Snake growth
- Score tracking
- High-score tracking
- Boundary collision detection
- Self-collision detection
- Game-over screen
- Restart functionality
- Responsive and minimalist UI

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- JavaScript Events
