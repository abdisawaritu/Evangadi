# Calculator Web Application

## 1. Project Overview

The Calculator Web Application is a responsive frontend calculator built to practice and demonstrate core web development skills learned in Phase 1 and Phase 2.

The project uses HTML, CSS, Bootstrap, JavaScript, and DOM manipulation to create an interactive calculator interface and implement basic arithmetic operations.

## 2. Objectives

The main objectives of this project are to:

- Build a professional calculator user interface.
- Practice HTML structure and semantic elements.
- Apply CSS and Bootstrap for responsive design.
- Use JavaScript to handle user interactions.
- Practice DOM selection and manipulation.
- Handle browser events.
- Implement arithmetic operations and calculation logic.
- Practice JavaScript functions, conditions, and data handling.

## 3. Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript (Vanilla JavaScript)
- DOM API
- Git and GitHub

## 4. Calculator Features

The calculator will provide:

- Number input (`0–9`)
- Double-zero input (`00`)
- Decimal input (`.`)
- Addition (`+`)
- Subtraction (`−`)
- Multiplication (`X`)
- Division (`÷`)
- Percentage (`%`)
- Parentheses (`( )`)
- Backspace (`⌫`)
- Equal (`=`)
- Responsive calculator interface

## 5. User Interface

The calculator uses a 5-row × 4-column button layout:

    ( )     ⌫      %      X
     7      8      9      ÷
     4      5      6      −
     1      2      3      +
     00     0      .      =

The display is positioned above the calculator buttons and shows the current input and calculation result.

## 6. Functional Requirements

The application should:

1. Accept numbers entered through the calculator buttons.
2. Accept decimal and double-zero input.
3. Perform addition, subtraction, multiplication, and division.
4. Support percentage calculations.
5. Support parentheses where applicable.
6. Remove the last entered character using the backspace button.
7. Calculate and display the result when `=` is pressed.
8. Prevent invalid calculations where possible.
9. Update the display dynamically without reloading the page.
10. Work correctly on different screen sizes.

## 7. Learning Focus

## 8. Project Development Approach

The calculator will be developed incrementally:

1. Project setup
2. HTML structure
3. CSS styling

5. Number input
6. Arithmetic operations
7. Calculation with `=`
8. Backspace functionality
9. Decimal and `00` functionality
10. Percentage and parentheses
11. Validation and edge cases
12. Final testing and refinement

## 9. Version Control

Git will be used to create checkpoints after each meaningful development stage.

Each checkpoint represents a working version of the application.

    git add .

## 10. Expected Outcome

At completion, the project will provide a responsive and fully interactive calculator that demonstrates practical application of HTML, CSS, Bootstrap, JavaScript, DOM manipulation, and event handling.
