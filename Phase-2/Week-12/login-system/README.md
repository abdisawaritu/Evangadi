# Login System

A professional, responsive login interface built for learning and practicing frontend development.

## Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## Features

* Email and password fields
* Show/hide password
* Form validation
* Error messages
* Loading and success states
* Responsive design
* DOM manipulation
* Event handling

## Project Structure

```text
login-system/
├── assets/
│   ├── images/
│   └── icons/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md
```

## Project Goal

Build a professional frontend login system and later extend it into a real authentication system with a backend and database.

## Git Workflow

Each major development stage will be:

```text
Build → Test → Commit → Push → Next Stage
```
