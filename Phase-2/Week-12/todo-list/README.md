# TaskFlow — To-Do List Application

A responsive frontend To-Do List application for creating, managing, and organizing daily tasks.

## Features

- Add new tasks
- Display tasks dynamically
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Filter tasks by status
- Display task statistics
- Responsive design
- Client-side validation

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- DOM Manipulation
- Git & GitHub

This project is designed to practice frontend development concepts including arrays, objects, functions, DOM manipulation, event handling, array methods, dynamic rendering, and application state.
