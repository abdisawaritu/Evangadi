How the order is created

You do not need to enter order_id, product_id, or user_id manually.

After the product is inserted, MySQL generates the product_id.

After the user is inserted, MySQL generates the user_id.

The Express server then uses these two generated IDs to create the order automatically.

Product → product_id
User → user_id
Order → product_id + user_id

Fields marked with * are required.

The server will insert the related records into the database.
